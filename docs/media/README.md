# DSH Office 功能演示

[返回项目首页](../../README.md)

## 01 工作区入口

在右侧工作区点击 `.docx`、`.xlsx` 或 `.pptx` 文件即可打开。Office 沿用当前账号及目录授权。

![01：工作区文件入口](chapters/01.png)

## 02-04 Word

默认进入预览。菜单保留在文档上方，切换编辑后使用文字、段落和表格等功能，点击“保存到工作区”写回原文件。保存前核对文件版本，冲突时拒绝覆盖并保留当前草稿。
