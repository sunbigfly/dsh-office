# 使用指南

[返回首页](../README.md)

## 支持的文件

| 文档 | 扩展名 | 打开方式 |
| --- | --- | --- |
| Word | `.docx` | 默认预览，可切换编辑并保存 |
| Excel | `.xlsx` | 默认预览，可切换编辑并保存 |
| PowerPoint | `.pptx` | 默认预览，可切换编辑并保存 |
| Markdown 及其他文件 | `.md` 等 | 使用 DSH 原生查看方式 |

## 使用体验

- **直接在工作区打开**：匹配这三类文件后接管右侧预览，无需另开文档应用。
- **预览和编辑共用菜单**：编辑、返回预览和保存位于编辑器菜单栏右侧。
- **适应侧栏宽度**：菜单放不下时折叠到“更多”，优先保留操作按钮；格式和绘图工具栏分别横向滚动，也可聚焦后使用左右方向键。
- **文档缩放**：鼠标位于编辑器内时，按住 `Ctrl` 滚动滚轮缩放文档，预览与编辑均可使用；普通滚轮仍用于滚动。
- **紧凑的中文界面**：90% 显示比例、固定 Paper 菜单布局、字体搜索和常用字体排序，任务面板默认收起。
- **宠物默认隐藏**：需要时从“帮助 → 显示助手”手动打开。
- **保存冲突保护**：保存前核对文件版本；其他人或工具已更新文件时，拒绝覆盖并保留当前编辑草稿。

## 安装

### 从 DSH 自定义索引安装

1. 在有管理权限的 DSH 中打开 **插件 → 实验性插件 → 自定义插件索引**。
2. 添加索引源：

   ```text
   https://github.com/sunbigfly/dsh-office/releases/latest/download/index.json
   ```

3. 在“发现”中搜索 **DSH Office**，安装并启用。
4. 刷新浏览器，在工作区点击 `.docx`、`.xlsx` 或 `.pptx` 文件。

索引固定到发行版的完整提交 SHA，安装的源码版本可追溯。已安装的旧版本可通过原生插件管理更新。

### 使用安装包

从 [Releases](https://github.com/sunbigfly/dsh-office/releases/latest) 下载 `dsh-office-0.1.0.tgz`，通过 DSH 原生插件安装入口安装。远程部署时，使用宿主服务器可访问的安装包路径。Release 同时提供 `SHA256SUMS` 校验文件。

从本地源码安装时，将本仓库目录作为插件目录添加到 DSH 即可。

## 日常使用

1. 在会话右侧工作区中打开文档，首先进入预览。
2. 点击菜单栏右侧的“编辑”，修改文档。
3. 点击“保存到工作区”，或使用 `Ctrl+S` / `⌘S` 保存。
4. 保存完成后可返回预览；遇到保存冲突时，先保留当前草稿，再重新读取文件。

编辑草稿保留在当前页面内。关闭文档、刷新或离开页面前会提示未保存的修改；完成编辑后请先保存。单个文件上限为 **32 MiB**。

## 文件和权限

| 使用场景 | 访问范围 |
| --- | --- |
| 原生 DSH 宿主 | 读写当前会话工作目录内的文档 |
| 多用户服务中的成员 | 在管理员授权内使用插件，编辑本人个人目录中的文档 |
| 多用户服务中的管理员 | 编辑已获管理权限的成员目录中的文档 |
| 已授权共享目录 | 支持预览；共享目录写入取决于现有文件接口，当前版本不提供此写入能力 |

插件复用 DSH 与多用户服务已有的文件、目录和插件使用授权。关闭文件权限或撤销插件使用授权后，不能继续通过本插件打开或保存文件。安装、全局启停和卸载由具有相应管理权限的人操作。

**DSH Office 独立安装和启停。** 管理员可在 DSH 原生插件页统一管理；停用后由 DSH 原生查看方式处理文件。多用户插件负责已有的账号与权限管理，本插件提供文档预览和编辑。

## 文档处理边界

编辑器运行在无同源权限的沙盒 iframe 中。父页面通过已授权的 DSH 接口读取文件并传入字节，保存也只回写到部署的 DSH。iframe 无法读取 DSH Cookie、账号数据或直接调用文件接口；文档内容不上传至 VibeOffice 网站。

复杂排版、图表、动画与特殊 OOXML 功能的兼容性沿用上游。需要严格保留版式的文件，请保留原件并核对保存结果。

## 开发与验证

```bash
npm run check
npm test
npm pack --pack-destination output
```

插件适配层使用 Node.js 内置模块与 DSH 现有服务，编辑器代码随插件打包。本仓库提供文件边界、并发保存、预览只读、菜单自适应、滚轮缩放、主题与局域网 HTTP 兼容检查；当前 **29 项自动检查通过**，并在原生 DSH 浏览器中验证三类文件的预览、编辑、保存及窄侧栏布局。

目录说明：

| 路径 | 用途 |
| --- | --- |
| `client.js` | 工作区文件匹配、侧栏和保存交互 |
| `index.js` / `files.js` | 静态资源与宿主文件接口适配 |
| `embed/` | 沙盒消息、菜单、自适应和初始化设置 |
| `vendor/` | 随插件分发的编辑器和显示适配 |
| `tests/` | 自动检查和合成文档样例 |
| `assets/` | 插件矢量 Logo 与 README 展示图 |

发布时，在提交后运行 `npm run release:index` 生成 `output/index.json`，与安装包及校验和一并上传到 Release。索引作为发行附件发布，使初始源码提交保持完整且可直接安装。
